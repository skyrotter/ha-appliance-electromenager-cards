# Consignes pour Claude

## Signature des messages publics

Tout message destiné à l'extérieur (commentaire d'issue ou de PR, message de forum, réponse à un utilisateur, etc.) se termine par cette signature, avant la mention « Generated by Claude Code » :

```
---
Si ce projet te plaît et que tu veux y contribuer, tu peux faire un don ou laisser une étoile sur le dépôt ⭐

❤️ [Sponsor sur GitHub](https://github.com/sponsors/skyrotter) · 💙 [Don via PayPal.me](https://paypal.me/skyrotter) · ☕ [Buy me a coffee](https://buymeacoffee.com/skyrotter)
```

Sur un support sans Markdown (forum en texte brut), mettre les liens en clair.

## Nouvelles cartes

Toute nouvelle carte (ou nouveau type d'appareil) doit être ajoutée :
- à une catégorie dans `CATS` de `src/cards/picker.js` (sélecteur de la carte unique) : le build avertit quand une carte n'en a pas ;
- au tableau « The cards » du `README.md` (et à ses traductions) ;
- avec sa fiche dans `docs/cards/`.
