# Water softener (generic)

This card is now an option of the [water softener card](water-softener.md): use `model: generic`.

```yaml
type: custom:appliance-water-softener-card
model: generic
```

`custom:appliance-water-softener-generic-card` still works (same card, `model: generic` by default), so existing dashboards keep working.
